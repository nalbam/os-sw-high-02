# 클린턴 - 청소 당번 알림 서비스

청소 당번 차례를 자꾸 잊어버리는 반, 동아리, 쉐어하우스를 위한 정적 웹 서비스 MVP입니다.
구성원과 시작일, 청소 주기를 입력하면 오늘의 당번과 앞으로 7번의 순서를 자동으로 보여줍니다.

## 주요 기능

- 구성원 이름을 쉼표 또는 줄바꿈으로 입력해 순번표 생성
- 시작일과 청소 주기를 기준으로 오늘의 담당자 자동 계산
- 청소 완료 버튼으로 다음 당번을 맨 앞으로 이동
- 브라우저 `localStorage` 저장으로 새로고침 후에도 설정 유지
- 브라우저 Notification API를 활용한 알림 권한 요청 데모

## 실행 방법

별도 빌드 과정 없이 브라우저에서 `index.html`을 열면 됩니다.
로컬 서버로 확인하려면 다음 명령을 사용할 수 있습니다.

```bash
python3 -m http.server 8000
```

그 다음 <http://localhost:8000>에 접속합니다.
